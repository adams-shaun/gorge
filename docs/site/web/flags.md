# gorged flags

`gorged` reads its flags with Go's standard `flag` package (`server/gorged`, `serveFlags`). It has no
config file and no environment variables of its own. `gorged -h` prints the same list with the bot-policy
options added. Single and double dashes both work (`-addr` or `--addr`), and a boolean is switched off with
`-name=false`.

Defaults worth knowing:

- `-addr` defaults to `:8080`, every interface, and that stays the default. Examples here use `127.0.0.1:8090` to keep a trial server on
  loopback; pick any free port (8090-8099).
- `-dir` defaults to `gorged-data`. Give each server its own directory, such as `/tmp/gorge-try`. Two servers sharing
  one corrupt each other ([Troubleshooting](../guide/troubleshooting.md)).
- `-prewarm` is on, so a fresh server fetches card art for every dealt deck at start. Pass `-prewarm=false` offline.

The table below is generated from the flag set of the `cmd/gorged` binary. `TestFlagsDocIsCurrent` fails when it
differs, so it cannot fall behind. A binary that links a trained-network bot adds a `-<policy>-net` family of flags
for it. `make deploy-demo` serves the demo (`deploy/demo.env.example`). The guides explain the flags in use: [Play in the browser](../guide/play.md),
[Draft events](../guide/draft.md), [Serving dirac](../guide/dirac.md).

`scripts/deploy-demo.sh` can serve a binary other than `cmd/gorged`. Set `SERVER_MAIN` in `deploy/demo.env` to a directory holding a `main.go` that wraps `gorged.Main`; the script builds it against this checkout and serves it, passing `SERVER_EXTRA_ARGS` on every server's command line and filling card art for `SERVER_EXTRA_DECKS` first. `scripts/deploy-demo.sh --dry-run` prints the resolved configuration, the build commands and each server's command line without building or starting anything.

| Flag | Default | Meaning |
|---|---|---|
| `-addr` | `:8080` | listen address |
| `-allow-decklist-bots` | `false` | let the server's own bot-only tables run a bot policy that reads every seat's real decklist; such a policy never seats against a human |
| `-art-dir` | none | durable card-art cache directory (default <dir>/art, which deploy scripts wipe with the persistence dir) |
| `-auto-mana` | `true` | enable automatic mana payment plans and controls for human seats (disable with -auto-mana=false for the legacy manual path) |
| `-bot-auto-mana` | `true` | have hosted bots and human-seat caretakers cast through offered automatic mana payment plans |
| `-bot-common-sense` | `false` | wrap hosted bots and human-seat caretakers in the bots/sanity CommonSense guard (drop hostile self-removal from the option list, answer the London mulligan by the constructed policy); opt-in, default off |
| `-bot-config` | none | read a bot policy's options from a JSON object file: <policy>=<file.json> (repeatable; overrides built-in defaults, below -bot-opt and the environment) |
| `-bot-opt` | none | set a bot policy option: <policy>.<key>=<value> (repeatable; overrides -bot-config and the environment) |
| `-bot-policies` | none | comma-separated set of bot policies this server OFFERS (the /api/bot-policies listing and accepted POST /api/games names); empty offers every registered entry that does not read opponents' decklists (a decklist-reading policy can never be offered: vs-bot always seats a human) |
| `-bot-policy` | `lethal-pressure` | default hosted bot policy for a vs-bot request that omits bot_policy; must be registered, offered, and support both formats (registered: az-redeal, az-redeal-maxn, bot, cast-profile, forge-heuristic, forge-heuristic-hold, lethal-pressure, sb-first, sb-heuristic, sb-search-lite-atk, sb-tactical, sb-uniform, search) |
